# 쇼츠 품질 A/B/C 시험 (spike/shorts-quality-ab, 2026-10-25)

`작업계획서_영상생성_3차_Claude모션스킬.md` 의 V-단계 중 일부(V-3 효과음·V-4 보상 무음·V-6 진행 표시·V-7 예능 스타일)와 "이미지 없는 모션그래픽"이 실제로 품질을 올리는지 같은 소재로 비교했다. 비용 0(이미지 재사용·코드 그림), 엔진 기본 동작은 그대로.

## 소재와 버전

소재: 10/24 「AI 트렌드 2026」 잡(트렌드 6가지 목록형, ComfyUI 이미지 8장)을 재사용.

| 버전 | 내용 |
|---|---|
| A | 현재 엔진(U-1~U-4) 그대로 다시 빌드. 강조어만 B 와 같게 수동 지정(로컬 LLM 이 빈 답이라) |
| B | A 와 같은 음성·이미지 + `look: "variety"`(예능 자막, Jua 글꼴) + `thread`(위쪽 진행 점·이름 스티커·결정적 장면에서 2열 격자로 모임) + `payoff`(직전 0.6초 무음 → 하드컷 + 가장 큰 타격음) + 강조어 순간 이미지 펀치인 + 화면 원인 있는 효과음 |
| C | B 와 같은 음성·자막·진행 표시·무음, 이미지 8장만 `kind: "mograph"` 코드 그림으로 교체 — 주인공 캐릭터 하나, 트렌드마다 빛줄기 +1, 나레이션 단어 큐 23개에 맞춘 동작, 주인공에서 번지는 전환(`hero_flood`) |

## 남은 것

- 강조어·진행 표시 항목·결정적 장면 위치·C 의 장면 그림과 단어 큐는 시험 스크립트에서 손으로 넣었다. 정식화하려면 기획서에서 자동으로 나와야 한다.
- C 는 이 대본 전용 그림 8종이다. 프롬프트로 바뀌게 하려면 소재 무관 "동작 틀" 라이브러리(+ 무료 아이콘 세트)나 영상마다 새로 짜는 방식이 필요하다(사용자 결정 대기).
- 결정적 장면 직전 약 0.2초는 측정상 −98~−136dB 로 여전히 매우 조용하다. 청취 확인 필요.
- 렌더 결과물은 `data/shorts/ab_compare/`(gitignore). 재현은 `scripts/spikes/shorts_ab/build_{a,b,c}.py`(메인 체크아웃의 원본 잡·루나 BGM 경로를 인자로 받음).
