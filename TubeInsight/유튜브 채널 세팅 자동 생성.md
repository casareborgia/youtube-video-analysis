유튜브 채널 세팅 자동 생성 — 명세

주제 한 줄을 넣으면 채널 개설에 필요한 값이 전부 나오게 한다.

1. 먼저 — 자동화되는 것과 안 되는 것

여기를 착각하면 만들 수 없는 걸 만들려다 시간을 버린다.

자동화되는 것

· 이름, 핸들, 설명, 키워드 생성 — LLM

· 프로필, 배너 이미지 생성 — 이미지 모델

· 핸들 중복 확인 — [youtube.com/@핸들](http://youtube.com/@%ED%95%B8%EB%93%A4) 응답 코드 확인

· 채널 설명, 키워드 등록 — Data API channels.update

· 영상 업로드, 기본값 적용 — Data API videos.insert (OAuth)

자동화되지 않는 것

· 채널 생성 자체 — API가 없다. 사람이 직접 만든다

· 프로필, 배너 이미지 업로드 — API가 없다. 스튜디오에서 사람이 올린다

· 전화 인증, 신분증 인증 — 사람이 직접

프로그램의 역할은 값과 이미지를 다 만들어 주고 사람은 붙여넣기와 업로드만 하게 하는 것이다. 채널을 대신 만들어 주는 게 아니라 채널 만들 재료를 완성해 주는 것이다.

1. 입력

topic (필수) — 주제 한 줄. 예: 50대 은퇴자를 위한 AI 활용법

lang (필수) — 사용자가 고른다. 기본값을 두지 않는다. BCP-47 코드 (ko, en, ja, es 등)

audience — 대상. 비우면 topic에서 추론

tone — 말투와 분위기. 예: 차분한, 유쾌한

persona\_type — character(캐릭터) / person(실사) / symbol(로고형). 기본 character

audio\_lang — 영상에서 말하는 언어. 비우면 lang을 따른다

1. 언어 규칙

lang 하나가 결과 전체를 바꾼다. 항목마다 적용 방식이 다르다.

lang 언어로 만드는 것

· 채널 이름, 설명, 키워드

· 업로드 기본값 (제목, 설명, 태그)

· 개설 체크리스트

언제나 영문 소문자로 만드는 것

· 핸들 — 유튜브가 한글, 가나, 한자를 받지 않는다

언제나 영어로 만드는 것

· 이미지 프롬프트 문장 — 이미지 모델이 영어에서 가장 안정적이다

· 단, 배너에 들어갈 글자는 lang 언어로 하되 프롬프트 안에 따옴표로 원문 그대로 박는다

비영어권 핸들 만드는 법

lang이 영어가 아니면 채널 이름을 그대로 핸들로 쓸 수 없다. 세 갈래로 후보를 만든다.

1. 로마자 표기 — 은퇴후AI연구소 → euntoe-ai  
2. 뜻을 옮긴 영어 — retire-ai, ai-after50  
3. 짧은 조합 — seniorailab

배너와 프로필 글자 주의

이미지 모델은 라틴 문자가 아닌 글자를 자주 뭉갠다. lang이 한국어, 일본어, 중국어라면 배너에 글자를 넣지 않거나 아주 짧게 하고, 채널 이름 텍스트는 나중에 사람이 얹는 편이 낫다. 프롬프트에 no text를 넣어 아예 비워두는 선택지도 함께 제시한다.

1. 출력 — 8개 항목

① 채널 이름 (channel\_name)

· 50자 이내

· 한글 기준 8자 이내가 기억에 남는다

· 검색어가 들어가면 유리하되 설명문이 되지 않게

② 핸들 후보 (handles) — 3개에서 5개

· 3자에서 30자, 영문 소문자와 숫자와 밑줄과 하이픈과 마침표만

· 한글 불가, 대소문자 구분 없음

· 선점제라 하나만 주면 대부분 실패한다. 반드시 여러 개

· 각 후보에 중복 확인 결과를 붙인다

· 확인법: [https://www.youtube.com/@핸들](https://www.youtube.com/@%ED%95%B8%EB%93%A4) 로 GET 요청. 404면 사용 가능, 200이면 이미 있음

③ 채널 설명 (description)

· 1,000자 이내

· 첫 두 줄이 검색 결과와 미리보기에 노출된다. 여기에 누구를 위한 무슨 채널인지를 넣는다

· 구성: 한 줄 정의 → 누구에게 도움이 되는지 → 업로드 주기 → 연락처와 링크

④ 채널 키워드 (keywords)

· 전체 합쳐 500자 이내

· 8개에서 15개 권장

· 넓은 것(예: AI)과 좁은 것(예: 로컬AI 설치)을 섞는다

· 공백이 든 키워드는 API로 보낼 때 큰따옴표로 감싼다

⑤ 프로필 이미지 프롬프트 (avatar\_prompt)

· 규격: 정사각형 800×800, 4MB 이하

· 실제로는 아주 작게 보인다. 프롬프트에 반드시 넣을 것:

단순한 단색 배경 / 중앙에 대상 하나만 / 얼굴이나 심볼이 프레임의 60% 이상 / 잔글씨 없음

· 비율은 이미지 모델에 설정값으로 넘긴다. 프롬프트 문장으로 비율을 적으면 먹지 않는다

⑥ 배너 이미지 프롬프트 (banner\_prompt)

· 규격: 2048×1152 (16대 9), 6MB 이하

· 가장 자주 실패하는 항목이다. 기기마다 보이는 영역이 다르다

TV는 2048×1152 전체

데스크톱은 가로가 잘린다

모바일은 정중앙 1235×338만 보인다

· 프롬프트에 반드시 넣을 것:

모든 텍스트와 주요 요소를 정중앙 가로 띠 안에 배치

좌우 가장자리는 배경만, 아무것도 두지 않음

위아래 여백 넉넉히

· 텍스트를 넣을 거면 한 줄로 짧게. 이미지 모델은 긴 문장을 자주 망친다

⑦ 업로드 기본값 (upload\_defaults)

매 영상마다 반복 입력을 없앤다. 자동 업로드에도 그대로 쓴다.

· title\_template — 예: {주제} — {한 줄 요약}

· description\_template — 5,000자 이내, 고정 소개문과 링크

· tags — 합쳐 500자 이내

· category\_id — 27 교육 / 28 과학기술 / 22 인물과 블로그 / 26 하우투와 스타일 / 24 엔터테인먼트

· privacy\_status — private로 시작 권장

· made\_for\_kids — 보통 false

· default\_language — 입력 lang을 그대로

· default\_audio\_language — 입력 audio\_lang, 없으면 lang

⑧ 개설 체크리스트 (setup\_steps)

사람이 직접 해야 하는 것을 순서대로 출력한다.

1. 구글 로그인 → YouTube → 프로필 → 채널 전환 → 모든 채널 보기 → 채널 만들기  
2. 이름과 핸들 입력 (위 후보 중 available이 true인 것)  
3. 프로필 이미지 업로드  
4. 배너 이미지 업로드  
5. 전화번호 인증 — 이걸 안 하면 15분 초과 영상과 커스텀 썸네일이 잠긴다  
6. 거주 국가와 키워드 설정  
7. 업로드 기본값 등록  
8. (선택) 신분증 인증 — 승인에 하루에서 이틀  
9. 출력 JSON

{

"topic": "50대 은퇴자를 위한 AI 활용법",

"lang": "ko",

"audio\_lang": "ko",

"channel\_name": "은퇴 후 AI 연구소",

"handles": \[

{ "handle": "retire-ai",   "available": true },

{ "handle": "ai-after50",  "available": false },

{ "handle": "seniorailab", "available": true }

\],

"description": "…",

"keywords": \["AI 입문", "50대 AI", "은퇴 준비"\],

"avatar\_prompt": "…",

"banner\_prompt": "…",

"upload\_defaults": {

"title\_template": "…",

"description\_template": "…",

"tags": \["…"\],

"category\_id": 27,

"privacy\_status": "private",

"made\_for\_kids": false,

"default\_language": "ko",

"default\_audio\_language": "ko"

},

"setup\_steps": \["…"\]

}

1. 검증 규칙 — 생성 후 반드시 확인

· channel\_name — 50자 이내인가. 넘으면 다시 생성

· handle — 3자에서 30자이고 영문 소문자와 숫자와 밑줄과 하이픈과 마침표만 썼는가. 위반한 후보는 제거

· handles — available이 true인 것이 하나 이상인가. 없으면 후보를 더 만든다

· description — 1,000자 이내인가. 넘으면 자른다

· keywords — 합계 500자 이내인가. 넘으면 뒤에서부터 뺀다

· tags — 합계 500자 이내인가. 넘으면 뒤에서부터 뺀다

· category\_id — 유효한 ID인가. 아니면 27로 대체

· lang — BCP-47 형식인가. 아니면 사용자에게 다시 묻는다. 임의로 ko를 넣지 않는다

· 생성된 텍스트 — 전부 lang 언어인가. 다른 언어가 섞였으면 재생성

1. 자동 등록까지 갈 경우 (선택)

이미지 업로드는 안 되지만 설명과 키워드는 API로 넣을 수 있다.

· 엔드포인트: channels.update, part=brandingSettings

· 권한: [https://www.googleapis.com/auth/youtube](https://www.googleapis.com/auth/youtube) — 읽기 전용 스코프로는 안 된다

· 넣을 수 있는 것: brandingSettings.channel.description, keywords, defaultLanguage

· 넣을 수 없는 것: 프로필 사진, 배너 이미지, 핸들, 채널 이름

업로드 할당량

기본 하루 10,000이다. videos.insert 한 건이 1,600을 쓰므로 하루 약 6편이 상한이다. channels.update는 50\. 자동화해도 무제한이 아니다.

주의

OAuth 앱이 구글 검증을 받기 전에는 업로드한 영상이 비공개로 잠길 수 있다. 올렸는데 안 보인다는 것은 정상 동작이므로 미리 안내한다.
