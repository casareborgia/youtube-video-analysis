# 🎬 TubeInsight AI — 유튜브 영상 0원 완전 분석 & 8초 비디오 기획 도구

유튜브 링크 하나로 **메타데이터 · 자막 전문 · 상위 댓글**을 수집하고, 내 컴퓨터의 **로컬 AI(LM Studio)** 로 흥행 공식을 분석합니다. 분석된 공식을 바탕으로 새 주제의 **8초 씬별 대본 + AI 영상 프롬프트 + 나레이션 오디오**까지 자동 생성합니다.

- 외부 유료 API 없음 — **API 키가 전혀 필요 없습니다 (0원)**
- 분석용 AI는 100% 내 컴퓨터에서 실행 (LM Studio)
- 나레이션은 무료 Edge-TTS 사용

---

## 1. 설치 방법

### 준비물
| 항목 | 설명 |
|---|---|
| Python 3.9 이상 | https://www.python.org/downloads/ |
| LM Studio **또는** Ollama | 로컬 AI 실행용 (무료) — 둘 중 하나만 있으면 됩니다 |

### ① Python 패키지 설치
터미널에서 이 폴더로 이동한 뒤:

```bash
pip3 install -r requirements.txt
```

### ② 로컬 AI 설정 — 둘 중 하나만 하면 됩니다 (자동 감지)

**방법 A. LM Studio** (https://lmstudio.ai)
1. LM Studio를 실행하고 한국어를 잘하는 모델을 다운로드합니다. (추천: `google/gemma-3-12b` 등)
2. 왼쪽 메뉴 **Developer(개발자) → Local Server** 에서 서버를 **Start** 합니다. (포트 1234 기본값)

**방법 B. Ollama** (https://ollama.com)
1. Ollama를 설치합니다. (설치하면 백그라운드 서버가 자동 실행됩니다)
2. 터미널에서 모델을 하나 받습니다:
   ```bash
   ollama pull gemma3          # 기본 추천 (한국어 우수, 약 3GB)
   ollama pull gemma3:12b      # 더 좋은 품질 (약 8GB, 램 16GB 이상 권장)
   ```
3. `ollama list` 로 모델이 보이면 준비 끝입니다.

> 앱이 LM Studio(1234) → Ollama(11434) 순서로 자동 감지해 연결합니다. 둘 다 켜져 있으면 LM Studio를 우선 사용합니다.
> 직접 고르고 싶으면 **화면 상단의 LM Studio / Ollama 배지를 클릭**하세요. 클릭한 쪽을 사용하고(검은 테두리), 다시 클릭하면 자동 모드로 돌아옵니다. 선택은 재시작 후에도 유지됩니다.
> 로컬 AI를 켜지 않아도 앱은 실행되지만, AI 분석 대신 "다른 AI에 붙여넣을 수 있는 프롬프트"가 제공됩니다.

## 2. 실행 방법

```bash
python3 server.py
```

실행 후 브라우저에서 **http://localhost:8989** 를 열면 됩니다.

## 3. 사용 순서 (단계별)

1. **① 영상 분석** — 벤치마크할 유튜브 링크를 붙여넣고 "분석 시작". 제목 훅 구조, 5단계 스토리 전개, 댓글 여론, 내 채널 적용 플레이북이 시각화됩니다.
   - 처음에는 "빠른 샘플" 버튼으로 미리 넣어둔 샘플 데이터를 바로 볼 수 있습니다.
2. **② 기획 & 나레이션 생성** — 새 영상 주제를 입력하면 제목 3종, SEO 설명란, 8초 단위 씬별 자막 대본, Runway/Kling용 영문 프롬프트, 씬별 나레이션 MP3(+전체 ZIP)가 생성됩니다.
3. 생성된 프롬프트를 AI 영상 툴(Runway, Kling, Sora 등)에 붙여넣어 8초 클립을 만들고, 나레이션 오디오와 합쳐 영상을 완성합니다.

## 4. 폴더 구조

```
server.py        웹 서버 (실행 진입점)
llm_client.py    로컬 AI 자동 감지 (LM Studio / Ollama)
analyze.py       유튜브 수집 + 로컬 AI 분석
generator.py     8초 씬 기획 & 프롬프트 생성
tts_engine.py    나레이션 TTS & 보이스 클로닝
index.html / style.css / app.js   웹 대시보드 화면
audio/           생성된 나레이션 오디오 (자동 생성)
voices/          내 목소리 프로필 (자동 생성)
output/          생성된 콘텐츠 기획서 저장 폴더 (자동 생성)
*_data.json      영상 분석 캐시 (샘플 2개 포함)
```

## 5. 자주 묻는 문제 (FAQ)

**Q. 상단에 "로컬 AI 꺼짐"이라고 떠요.**
→ LM Studio(Local Server, 포트 1234) 또는 Ollama(포트 11434) 중 하나가 켜져 있는지 확인하세요.

**Q. "Ollama 연결됨 — 모델 설치 필요"라고 떠요.**
→ Ollama는 실행 중인데 모델이 없는 상태입니다. 터미널에서 `ollama pull gemma3` 를 실행하세요.

**Q. 분석 시 "영상 정보를 가져오지 못했습니다" 오류가 나요.**
→ ① `pip3 install yt-dlp` 로 설치 확인 ② 인터넷 연결 ③ 비공개/삭제된 영상이 아닌지 확인하세요.

**Q. 나레이션 음성 생성이 안 돼요.**
→ Edge-TTS는 인터넷 연결이 필요합니다. (마이크로소프트 무료 TTS 서버를 사용)

**Q. '목소리 학습(내 목소리로 나레이션)'을 쓰고 싶어요.**
→ 선택 기능입니다. `requirements.txt` 하단의 `torch`, `qwen-tts` 주석을 해제하고 추가 설치하세요. (다운로드 용량이 큽니다)

**Q. 다른 사람이 제 서버에 접속할 수 있나요?**
→ 아니요. 서버는 127.0.0.1(내 컴퓨터 전용)에만 열리므로 외부에서 접근할 수 없습니다.

**Q. 인터넷 없이 사용할 수 있나요?**
→ 유튜브 데이터 수집, 나레이션 음성 합성, 화면 스타일(CDN)에 인터넷이 필요합니다. AI 분석 자체는 100% 로컬(LM Studio)에서 처리됩니다.
